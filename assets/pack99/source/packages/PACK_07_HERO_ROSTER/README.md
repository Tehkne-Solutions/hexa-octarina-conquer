# HOC Pack 07 — Hero Roster Final

Heróis incluídos:

- Guerreiro
- Necromante
- Ranger
- Sicário
- Guardião

Cada herói contém master, sombra, emissivo, quatro direções, equipamento,
retratos, HUD, arte de carta, três VFX, sete estados em quatro direções,
frames individuais, spritesheets, atlas JSON, state machine e manifesto.

## Resumo

- 5 heróis
- 20 direções
- 140 conjuntos de animação
- 780 frames
- footprint 1×1
- anchor [0.5, 0.91]
- display height 160 px
- frame canvas 256×256
- fundo transparente

Esta é a versão runtime-ready v1. Os IDs foram congelados para permitir
substituição futura da arte sem alteração no código.
