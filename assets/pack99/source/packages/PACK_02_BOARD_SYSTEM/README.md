# HOC Pack 02 — Board System Final

Este ZIP contém o sistema visual do tabuleiro em formato runtime-ready.

## Subpacks

### P01 — Pilares
- 6 estados
- base, sombra e emissivo quando aplicável
- grid role: interseções

### P02 — Arestas
- madeira, pedra e arcana
- orientações NE–SW e NW–SE
- preview, built, damaged e destroyed
- base, sombra e emissivo nas barreiras arcanas

### P03 — Evolução Territorial
- selo, acampamento, posto avançado, forte e cidadela
- estados neutral, blue, red, construction e damaged
- footprints e colisões incluídos

## Arquivos globais
- `pack-manifest.json`

- `board-system.ts`
- previews de validação sem texto
