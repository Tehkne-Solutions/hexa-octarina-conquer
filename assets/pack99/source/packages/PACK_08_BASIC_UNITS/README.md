# HOC Pack 08 — Basic Units Final

Unidades incluídas:

- Recruta
- Arqueiro
- Guardião
- Aprendiz Arcano
- Coletor
- Batedor
- Esqueleto
- Golem de Pedra

Cada unidade contém:

- master;
- sombra;
- emissivo;
- máscara recolorível de facção;
- quatro direções;
- cinco estados de animação;
- frames individuais;
- spritesheets;
- atlas JSON;
- retrato;
- ícone HUD;
- ícone de minimapa;
- VFX de ataque;
- state machine;
- manifesto individual.

## Estados

- idle
- walk
- attack
- hit
- defeat

## Resumo técnico

- 8 unidades
- 32 direções
- 160 conjuntos de animação
- 800 frames
- frame canvas 256×256
- footprint 1×1
- anchor [0.5, 0.91]
- display height 142 px
- fundo transparente

Esta é a versão runtime-ready v1. Os IDs, máscaras e atlas foram
congelados para permitir substituição futura da arte sem alteração de código.
