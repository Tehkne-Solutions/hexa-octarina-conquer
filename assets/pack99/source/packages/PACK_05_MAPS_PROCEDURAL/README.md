# HOC Pack 05 — Maps & Procedural Final

Pacote final de mapas, validação e geração procedural.

## Mapas incluídos
- MAP_TUTORIAL_5X5_01
- MAP_FOREST_FRONTIER_8X8_01
- MAP_OCTARINE_CONVERGENCE_12X12_01

Cada mapa contém seed, células, autotile, colisões, movimento, spawns,
landmarks, pilares, arestas, objetivos e preview.

## Dependências
- PACK 01 — Terrain Core
- PACK 02 — Board System
- PACK 03 — Resources
- PACK 04 — Props & Obstacles

As imagens não são duplicadas. Os mapas referenciam os IDs oficiais.
